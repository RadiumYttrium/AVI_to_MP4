# AVI_to_MP4
This repository contains a .py file that lets you convert .avi files to .mp4. Please ensure you have the latest Python version, else, see [https://www.python.org/downloads/](https://www.python.org/downloads/)

## Requirements
1) Please ensure you have Visual Studio Code installed.
2) Download or paste the code into your Visual Studio Code project and you will need the .avi files within the same directory as the .py file.
3) Run the code in a dedicated terminal (do **not** click on the play button, please press the down arrow and select "Run in a dedicated terminal")
4) The code will convert all of the .avi and create a folder called **converted_mp4s**, containing the converted files.
